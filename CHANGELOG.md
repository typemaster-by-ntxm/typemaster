# Changelog

All notable changes to TypeMaster for Windows and macOS. The format follows [Keep a Changelog](https://keepachangelog.com/) and versions follow [Semantic Versioning](https://semver.org/).

Downloads for every version are on the [releases page](https://github.com/typemaster-by-ntxm/typemaster/releases).

## [0.1.2] - 2026-10-03

Downloads: [Windows installer (MSI)](https://github.com/typemaster-by-ntxm/typemaster/releases/download/v0.1.2/TypeMaster_0.1.2_x64_en-US.msi) | [macOS Apple Silicon (DMG)](https://github.com/typemaster-by-ntxm/typemaster/releases/download/v0.1.2/TypeMaster_0.1.2_aarch64.dmg) | [release page](https://github.com/typemaster-by-ntxm/typemaster/releases/tag/v0.1.2)

### Added
- More stories. The bundled library now has **1,456 stories**, all available offline.

### Changed
- Story sublevels are larger.
- The desktop app is the single-user edition, installed with an MSI (`TypeMaster_0.1.2_x64_en-US.msi`, 525,088,150 bytes).

### Fixed
- Word wrapping in the typing area.

### Notes
- The Windows installer and executable are not code-signed yet, so SmartScreen may show a warning.
- There is a macOS build for Apple Silicon Macs (`TypeMaster_0.1.2_aarch64.dmg`, 527,406,169 bytes). Intel Macs are not supported.
- SHA-256 of the Windows installer: `6ceb838d32434452571fcb0af503d62270cb68b8b30e38cdbba43036111bbe67`.
- SHA-256 of the macOS disk image: `7c1632920e950d37912a5d947a2be6c755e54c889cff91ed11e5f2fc3c2303d5`.
