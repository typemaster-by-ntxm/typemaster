# Changelog

All notable changes to TypeMaster for Windows. The format follows [Keep a Changelog](https://keepachangelog.com/) and versions follow [Semantic Versioning](https://semver.org/).

Downloads for every version are on the [releases page](https://github.com/typemaster-by-ntxm/typemaster/releases).

## [0.1.2] - 2026-10-03

Downloads: [Windows installer (MSI)](https://github.com/typemaster-by-ntxm/typemaster/releases/download/v0.1.2/TypeMaster_0.1.2_x64_en-US.msi) | [release page](https://github.com/typemaster-by-ntxm/typemaster/releases/tag/v0.1.2)

### Added
- More stories. The bundled library now has **1,456 stories**, all available offline.

### Changed
- Story sublevels are larger.
- The desktop app is the single-user edition, installed with an MSI (`TypeMaster_0.1.2_x64_en-US.msi`, 525,088,150 bytes).

### Fixed
- Word wrapping in the typing area.

### Notes
- The Windows installer and executable are not code-signed yet, so SmartScreen may show a warning.
- There is no macOS build of this version.
- SHA-256 of the installer: `6ceb838d32434452571fcb0af503d62270cb68b8b30e38cdbba43036111bbe67`.
