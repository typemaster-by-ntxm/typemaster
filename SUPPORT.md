# Support

Need help with TypeMaster? Here is the quickest way to the right place.

| I want to... | Go here |
|:-------------|:--------|
| Install it, or get past the SmartScreen warning | [Install section of the README](README.md#install) |
| Know what is stored on my computer or sent over the network | [PRIVACY.md](PRIVACY.md) and [Privacy and offline](README.md#privacy-and-offline) |
| See the known limitations | [Known limitations](README.md#known-limitations) |
| Report a bug | [Open a bug report](https://github.com/typemaster-by-ntxm/typemaster/issues/new?template=bug_report.yml) |
| Suggest a feature | [Open a feature request](https://github.com/typemaster-by-ntxm/typemaster/issues/new?template=feature_request.yml) |
| Report a security problem | [SECURITY.md](SECURITY.md) (email, not a public issue) |
| Use the app in a school or share the installer | Email [contact@ntxm.org](mailto:contact@ntxm.org) |
| Anything else | [contact@ntxm.org](mailto:contact@ntxm.org), the [product page](https://ntxm.org/products/typemaster/) or the [web version](https://typemaster.ntxm.org/) |

When you report a problem, please include your TypeMaster version, your Windows version, what you clicked and the exact message you saw. Please do not attach private files.
